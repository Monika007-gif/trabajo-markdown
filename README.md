# trabajo-markdown

## Introducción

*Markdown es un lenguaje de marcas, para dar formato a textos de forma sencilla, sus símbolos no son complicados.*

1. Crea títulos
2. Crea listas numeradas
3. Textos en cursiva
4. Enlaces
5. Inserta imágenes
6. Textos en negrita
7. Tachar textos
8. Listas con viñetas
9. Lineas horizontales
10. Bloques de código
11. Citas destacadas
12. Organiza información en tablas con filas y columnas.

**Plantas medicinales**para ~~el~~ nuestro bienestar.
